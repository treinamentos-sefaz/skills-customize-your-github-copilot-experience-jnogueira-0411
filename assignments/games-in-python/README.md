
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo da Forca onde os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas. Nesta atividade você praticará manipulação de strings, loops, condicionais e seleção aleatória em Python.

## 📝 Tarefas

### 🛠️ Implementar a Lógica Principal do Jogo

#### Descrição
Crie um programa em Python que funcione como um jogo da Forca interativo. O programa deve gerenciar o estado do jogo e implementar as mecânicas principais.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Aceitar palpites de letras do usuário e validar as entradas
- Mostrar o progresso atual usando o formato de caracteres ocultados (exemplo: _ _ _ )
- Rastrear e exibir as tentativas incorretas restantes
- Encerrar corretamente quando a palavra for adivinhada ou as tentativas esgotarem
- Exibir mensagens claras de vitória ou derrota ao final do jogo
